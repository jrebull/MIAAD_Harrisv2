## How to compile (Overleaf)

1. Upload the whole folder (or the ZIP) to a new Overleaf project.
2. Set the compiler to **pdfLaTeX** and the main document to `main.tex` (named/camera-ready) or `main_submission.tex` (anonymized, double-blind).
3. Compile (2–3 passes; Overleaf does this automatically). No BibTeX/biber pass is needed — the bibliography is inline `thebibliography`.

The document targets **A4** (forced via `\AtBeginDocument{\pdfpagewidth=210mm \pdfpageheight=297mm}`, per the LNCS A4 requirement) and uses the official `llncs.cls`.
